GETTING STARTED

A quick guide to your inventory

Add items and recipes yourself—no code changes needed.

01

Add a new inventory item

  1. Open Master inventory and choose ＋ Add inventory item.
  2. Enter a clear name, category, and the unit your team counts in (pcs, kg, L).
  3. Set reorder, critical, and target levels in that same unit.
  4. Save. The item is ready in daily counts and production / stock-in forms.
Tip: Use one consistent unit. If you buy in cases but count in pieces, convert the received quantity to pieces.
02

Map a recipe / BOM

  1. Open Recipe / BOM and choose ＋ Add recipe mapping.
  2. Enter the menu item name as it appears in Loyverse.
  3. Select an inventory ingredient, then enter quantity used per serving.
  4. Add one mapping for every ingredient in the menu item.
Example: Cheeseburger → Patty 1 pc, Bun 1 pc, Cheese 1 slice. Names should match Loyverse sales exactly.
03

Complete the daily flow

  1. Production: production team records quantities prepared.
  2. Stocks in: manager records deliveries or transfers received.
  3. Night count: enter the physical ending count for each item.
  4. Next day: the saved physical ending becomes beginning automatically.
  5. Import Loyverse sales, then review the variance flags.
04

Understand the numbers

Beginning + Production + Stocks in = Total available
Total available − Physical ending = Actual used
Sales × Recipe/BOM = Expected used

Variance is actual usage minus expected usage. Default tolerance is 10%; the README explains where to adjust it. Review the source entries and investigate before correcting a count.
